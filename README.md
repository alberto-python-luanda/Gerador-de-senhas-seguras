# 🔐 Gerador de Senhas Seguras

![Python](https://img.shields.io/badge/Python-3.8%2B-blue)
![Security](https://img.shields.io/badge/Security-100%25-green)

Gerador de senhas fortes, seguras e aleatórias. Protege suas contas do Facebook, Gmail, bancos!

## ✨ Funcionalidades
- 🔑 Gera 5 senhas por vez
- 💪 Garante letra maiúscula, minúscula, número e símbolo
- 📏 Tamanho personalizável (8 a 32 caracteres)
- 🎲 100% aleatório e seguro

python app.py
